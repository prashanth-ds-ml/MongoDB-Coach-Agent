## Fix applied while building this map

`score_md_file_for_concept()` (in `src/certcoach/core/planner.py`) did not strip `$` from operator-name concepts before tokenizing, so a bare-operator concept like `$set` could never match its own dedicated reference doc filename (which never contains a literal `$`, e.g. `..._operator_update_set__....md`). Fixed by stripping `$` alongside the existing `()`/`/`/`-` stripping. Regression test: `tests/unit/test_study_runtime.py::test_score_md_file_for_concept_matches_bare_dollar_operator_names`. This measurably improved doc resolution for Topics 4, 7, and 8 (see below); flagged inline as "(fixed)".

## Regenerate this map

```python
from certcoach.core import planner

for topic in planner.load_syllabus():
    for concept in topic.get("subtopics", []):
        md_files = topic.get("md_files", [])
        matched = [f for f in planner.prioritize_md_files(md_files, concept)
                   if planner.score_md_file_for_concept(f, concept) > 0]
        print(topic["id"], concept, matched or f"(fallback: {md_files[:2]})")
```
