# Comparison Query Predicate Operators

Copy page

Comparison operators filter data with value comparisons such as less than and greater than.

For comparison of different BSON type values, see the [specified BSON comparison order](/docs/manual/reference/bson-type-comparison-order/#std-label-bson-types-comparison-order)[.](/docs/manual/reference/bson-type-comparison-order/#std-label-bson-types-comparison-order)

Operator

Description

`[$eq](/docs/manual/reference/operator/query/eq/#mongodb-query-op.-eq)`

Matches values equal to a specified value.

`[$gt](/docs/manual/reference/operator/query/gt/#mongodb-query-op.-gt)`

Matches values greater than a specified value.

`[$gte](/docs/manual/reference/operator/query/gte/#mongodb-query-op.-gte)`

Matches values greater than or equal to a specified value.

`[$in](/docs/manual/reference/operator/query/in/#mongodb-query-op.-in)`

Matches any values specified in an array.

`[$lt](/docs/manual/reference/operator/query/lt/#mongodb-query-op.-lt)`

Matches values less than a specified value.

`[$lte](/docs/manual/reference/operator/query/lte/#mongodb-query-op.-lte)`

Matches values less than or equal to a specified value.

`[$ne](/docs/manual/reference/operator/query/ne/#mongodb-query-op.-ne)`

Matches all values not equal to a specified value.

`[$nin](/docs/manual/reference/operator/query/nin/#mongodb-query-op.-nin)`

Matches if the value is not equal to any of a given list of values.
