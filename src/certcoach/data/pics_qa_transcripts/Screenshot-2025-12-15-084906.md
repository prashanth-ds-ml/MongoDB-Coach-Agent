Which query should you use? (Select one.)

A.

db.trips.find( { usertype: "Subscriber"},( sort: { tripduration: -1 }),{ limit :5 })

B.

db.trips.find( { usertype: "Subscriber"},( sort: { tripduration: 1 }),{ limit :5 })

C.

db.trips.find( { usertype: "Subscriber" }).sort( { tripduration: 1 }).limit(5)

D.

db.trips.find( { usertype: "Subscriber" }).sort( { tripduration: -1 }).limit(5)
