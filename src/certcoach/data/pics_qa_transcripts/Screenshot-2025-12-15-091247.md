You need to insert a new restaurant into the restaurants collection. The new restaurant’s data is stored in a Python dictionary, stored in the variable name hyderabadi_biryani. Which of the following expressions will insert the new document into the restaurants collection? (Select one.)

A.

result = restaurants.insert_one(hyderabadi_biryani)

B.

result = restaurants.insert(hyderabadi_biryani)

C.

result = restaurants.insert_many(hyderabadi_biryani)

D.

result = restaurants.insert.hyderabadi_biryani

Correct Answer

A. Option A
Correct! This expression will insert a single document, stored in the hyderabadi_biryani variable, into the restaurants collection.

B. Option B
Incorrect. Insert is not a valid method in PyMongo.

C. Option C
Incorrect. The insert_many method is used to insert multiple documents. You need to insert a single document.

D. Option D
Incorrect. The insert method does not exist in PyMongo. To insert a single document, you should use insert_one().
